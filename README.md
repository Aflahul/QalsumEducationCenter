# 🎓 Sistem Informasi LKP Qalsum Education Center

Proyek ini adalah **aplikasi web berbasis Laravel** yang dikembangkan untuk memenuhi kebutuhan **Lembaga Kursus dan Pelatihan (LKP) Qalsum Education Center** di Masamba, Luwu Utara.  
Sistem ini membantu proses administrasi lembaga kursus agar lebih modern, cepat, dan efisien dibandingkan cara manual.

---

## 🎯 Tujuan

- Mempermudah proses **pendaftaran siswa baru** (offline & online).  
- Menyediakan **dashboard admin** untuk mengelola data pegawai, instruktur, siswa, kelas, nilai, dan pembayaran.  
- Memberikan **informasi terbuka** kepada masyarakat melalui website (profil lembaga, jadwal kursus, program, agenda, galeri, berita, dan info penting).  
- Mengurangi beban kerja administrasi manual, sekaligus mempercepat pelayanan lembaga.

---

## 🚀 Fitur Utama

### 🔐 Admin
- Login sebagai administrator.  
- Kelola **pegawai**, **instruktur**, **siswa**, **kelas**, **nilai**, dan **pembayaran**.  
- Kelola konten web: profil lembaga, program kursus, jadwal, berita, agenda, galeri, info penting.  
- Cetak data siswa, pegawai, instruktur, dan nilai siswa.  

### 👨‍🎓 Siswa & Calon Siswa
- Melihat profil lembaga, program kursus, jadwal, galeri, berita, agenda, dan info penting.  
- Melakukan **pendaftaran online** yang otomatis dikirimkan ke admin.  
- Mendapatkan informasi status kelas dan kegiatan kursus.
